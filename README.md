## 2. Tujuan Praktikum

Praktikum ini bertujuan untuk menerapkan beberapa konsep HTML lanjutan dalam satu halaman web, yaitu:

1. Membuat tabel untuk menampilkan data.
2. Membuat form untuk menerima input pengguna.
3. Menggunakan berbagai jenis input HTML.
4. Menggunakan validasi dasar pada form.
5. Menerapkan semantic HTML pada struktur halaman.
6. Menambahkan multimedia berupa audio dan video.
7. Membuat halaman HTML yang dapat dibuka langsung melalui browser.

---

## 3. Dasar Teori

### 3.1 Table

HTML menyediakan elemen `<table>` untuk membuat tabel data.

Beberapa elemen yang digunakan dalam tabel yaitu:

- `<table>` untuk membuat tabel.
- `<tr>` untuk membuat baris tabel.
- `<th>` untuk membuat bagian header tabel.
- `<td>` untuk membuat data pada tabel.

HTML juga menyediakan atribut `colspan` dan `rowspan` untuk menggabungkan beberapa kolom atau baris.

---

### 3.2 Form

Form digunakan untuk menerima data dari pengguna.

Beberapa elemen yang digunakan antara lain:

- `<form>` sebagai container form.
- `<label>` sebagai label untuk input.
- `<input>` untuk menerima data.
- `<select>` untuk pilihan.
- `<textarea>` untuk input teks yang lebih panjang.
- `<button>` untuk menjalankan aksi.

Jenis input yang dapat digunakan antara lain:

- `text`
- `email`
- `password`
- `number`
- `date`
- `radio`
- `checkbox`

---

### 3.3 Validasi Form

HTML menyediakan atribut validasi dasar untuk membantu memeriksa input pengguna.

Pada praktikum ini digunakan beberapa atribut, yaitu:

- `required` untuk membuat input wajib diisi.
- `min` untuk menentukan nilai minimum.
- `max` untuk menentukan nilai maksimum.

---

### 3.4 Semantic HTML

Semantic HTML digunakan untuk memberikan makna pada struktur halaman.

Elemen yang digunakan dalam praktikum ini antara lain:

- `<header>` sebagai bagian kepala halaman.
- `<nav>` sebagai area navigasi.
- `<main>` sebagai konten utama.
- `<section>` untuk mengelompokkan bagian konten.
- `<footer>` sebagai bagian kaki halaman.

---

### 3.5 Multimedia

HTML dapat digunakan untuk menampilkan multimedia menggunakan:

- `<audio>` untuk audio.
- `<video>` untuk video.
- `controls` untuk menampilkan kontrol pemutaran.

File multimedia digunakan sebagai sumber pada elemen `<source>`.
